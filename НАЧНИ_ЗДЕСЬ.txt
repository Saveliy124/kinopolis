КИНОПОЛИС · ПРАКТИЧЕСКИЕ 1–12

1. Распакуйте архив целиком в отдельную папку.
2. На macOS/Linux выполните python3 -m cinema из папки проекта.
   На Windows запустите START.cmd двойным щелчком. Нужен Python 3.9 или новее.
3. Не закрывайте окно сервера.
4. Откройте http://127.0.0.1:8000/ в браузере.

Администратор новой учебной базы:
admin@cinema.local
Admin123!

Если сайт недоступен — проверьте, что окно сервера открыто.
Если порт занят: python3 -m cinema --port 8001
(на Windows: python -m cinema --port 8001)
и откройте http://127.0.0.1:8001/

Тесты: python3 -m unittest discover -s tests -v
Демонстрация REST при работающем сервере: python3 scripts/demo_api.py
(на Windows используйте python вместо python3)

Оформление сохранено. Для отдельного сервера подготовлены Docker и HTTPS,
но их запуск на целевой инфраструктуре нужно проверить отдельно.
Исходный архив не изменён. Готовая копия создаёт чистую учебную базу.
